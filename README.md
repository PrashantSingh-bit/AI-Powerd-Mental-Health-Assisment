# 🧠 MindNova — AI-Powered Mental Health & Cognitive Wellness Predictor

**MindNova** is an AI-powered web application designed to assess mental wellness and cognitive resilience using lifestyle and behavioral factors such as sleep, stress, screen time, physical activity, and recovery.

The application uses a **Machine Learning model** to analyze the provided information and generate a personalized cognitive resilience score.

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Shivam122gupta/Ai-powerd-Mental-Health-Predictor.git
```

### 2. Navigate to the project

```bash
cd Ai-powerd-Mental-Health-Predictor
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

## 📊 Machine Learning

MindNova uses a **Random Forest regression model** to generate cognitive resilience predictions.

The ML pipeline includes:

* Data cleaning
* Missing-value handling
* Feature transformation
* Numerical feature scaling
* Categorical feature encoding
* Model training and tuning

MindNova is an **educational and technology project** and is not intended to diagnose, treat, or replace professional medical or psychological advice.
